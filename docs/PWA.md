# 📲 SOBRE MÍDIA ERP v2.0 — MANUAL PWA (PROGRESSIVE WEB APP)

**Recursos PWA Homologados**

- **Instalação Nativa**: Suporte a adicione à tela inicial em dispositivos Android e iOS.
- **Service Worker Precaching**: Estratégia CacheFirst para assets estáticos e StaleWhileRevalidate para chamadas analíticas.
- **Background Sync**: Sincronização em segundo plano assim que a conectividade for detectada.
