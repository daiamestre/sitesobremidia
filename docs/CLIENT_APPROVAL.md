# 🎨 SOBRE MÍDIA ERP v2.0 — FLUXO DE APROVAÇÃO DE ARTES DE ANÚNCIO

**Esteira de Aprovação de Criativos**

1. A produção gera a mídia e envia para homologação.
2. O anunciante recebe a notificação no Portal e pré-visualiza o vídeo HD 1920x1080.
3. Se aprovado (`status: APROVADO_PELO_CLIENTE`), o Pedido de Inserção entra automaticamente em programação nos players.
4. Se rejeitado com ressalvas, a equipe de produção é notificada para gerar a versão N+1.
